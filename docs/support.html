Support

Most problems come down to Wi-Fi or a permission. Start here.

Getting the TestFlight

Farly is in beta on TestFlight for iPhone. Install Apple's TestFlight app, then open the Farly beta invite on your iPhone.

The Mac menu bar app is coming soon to TestFlight.

My TV does not show up

  • Make sure your phone and TV are on the same Wi-Fi network (not a guest network).
  • Allow Local Network for Farly in Settings → Privacy & Security → Local Network.
  • Turn the TV fully on, then scan again.
  • Still missing? Use Add by address with the TV's IP address from its network settings.

Pairing

  • Samsung: accept the "Allow" prompt on the TV the first time.
  • LG webOS: accept the connection request on the TV.
  • Android TV / Google TV: type the code shown on the TV into Farly.
  • Roku: no pairing needed. Make sure "Control by mobile apps" is enabled on the Roku.

Apple TV, Chromecast and Sony Bravia are detected but not controllable yet.

Mac menu bar app

Coming soon to TestFlight. Once it is out:

  1. On your phone, open the saved-devices drawer and tap Share with Mac. Keep Farly open.
  2. On the Mac, choose Import from phone and enter the 6-digit code and the address shown on the phone.
  3. If the import times out, allow Local Network for Farly in System Settings on the Mac.

Contact

Report a bug or ask a question on GitHub Issues. Please include your device, TV brand and model.
